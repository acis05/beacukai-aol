# IT Inventory KB — MVP pengujian
Belum siap untuk akses resmi Bea Cukai. Tidak ada koneksi live yang diuji.

## Instalasi
Python 3.11+, `python -m venv .venv`, aktifkan virtualenv, `pip install -r requirements.txt`. Salin .env.example ke .env. Ganti password admin dan SESSION_SECRET dengan nilai acak. Buat TOKEN_KEY dengan `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`. Isi kredensial OAuth hanya di server. Daftarkan redirect URI persis di Accurate Developer. Jalankan `uvicorn app:app --host 127.0.0.1 --port 8000`. Login admin dengan password .env. Hubungkan Accurate, lihat daftar database, isi ACCURATE_DB_ID, restart, sinkron master. Scope default item_view. OAuth mengikuti dokumentasi https://accurate.id/api-integration/oauth/ dan https://accurate.id/api-integration/api-example/.

## Data
Unduh template Excel dari UI. Import items untuk klasifikasi BB/BP/FG/WIP/ASET/SCRAP dan satuan. Simpan kode dan nomor dokumen sebagai teks agar nol awal terjaga. Import movements menggunakan referensi unik per baris transaksi, tanggal ISO, kode barang, kuantitas bertanda (masuk positif, keluar negatif), jenis IN/OUT/PROD/TRANSFER/ADJ/OPEN. OPEN harus sebelum awal periode laporan. Jangan memasukkan transaksi ganda (misalnya pengiriman dan faktur untuk barang yang sama). Import bc dengan ref baris mutasi yang sama. Saat ini satu dokumen per baris mutasi; relasi banyak-ke-banyak belum tersedia. Transfer internal jangan dihitung sebagai masuk/keluar kawasan; data agregat perusahaan, tanpa gudang. WIP/aset/scrap memerlukan data mutasi yang telah dipetakan, bukan otomatis dari nilai pekerjaan pesanan. Excel adalah jalur sementara untuk transaksi, bukan sinkronisasi otomatis. Impor ulang ref identik memperbarui baris; penghapusan/koreksi transaksi belum otomatis. Jangan gunakan untuk laporan resmi tanpa rekonsiliasi saldo fisik dan validasi format.

## Hosting
PostgreSQL: DATABASE_URL=postgresql+psycopg://... . Gunakan HTTPS, HTTPS_ONLY=true, reverse proxy tepercaya dengan origin/base URL yang sesuai, satu worker untuk uji OAuth. Jangan membuka server uji ke publik. Login dasar admin saja; role Bea Cukai, audit detail perubahan, backup, scheduler, sinkron transaksi, stock opname, PDF, CSRF tambahan dan pengujian keamanan perlu diselesaikan sebelum go-live. Endpoint, scope, struktur detail Pekerjaan Pesanan dan Penyelesaian Pesanan perlu diverifikasi dengan akun pengguna. Tidak ada endpoint tulis Accurate.
