# Deploy IT Inventory ke Railway
Versi MVP untuk uji internal, bukan sistem yang sudah tervalidasi Bea Cukai.
1. Ekstrak ZIP. Buat repository GitHub private. Upload seluruh isi ZIP ke root repository (termasuk file tersembunyi), commit. Jangan upload .env.
2. Railway: New Project, Deploy from GitHub repo. Pilih repository. Tambahkan PostgreSQL pada project yang sama. Nama service database diasumsikan Postgres.
3. Pada service aplikasi, Variables: DATABASE_URL=${{Postgres.DATABASE_URL}} (sesuaikan nama service), ADMIN_PASSWORD=password kuat unik, SESSION_SECRET=nilai acak panjang, TOKEN_KEY=kunci Fernet, HTTPS_ONLY=true. Buat SESSION_SECRET dengan `python -c "import secrets; print(secrets.token_hex(32))"` dan TOKEN_KEY dengan `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` (setelah install cryptography). Simpan kunci secara aman; jangan ganti sembarangan karena token lama tidak dapat dibaca.
4. Settings > Networking > Generate Domain. Isi PUBLIC_ORIGIN=https://DOMAIN dan ACCURATE_REDIRECT_URI=https://DOMAIN/oauth/callback (tanpa slash akhir pada origin). Isi ACCURATE_CLIENT_ID, ACCURATE_CLIENT_SECRET, ACCURATE_SCOPE=item_view. Daftarkan callback persis di Accurate Developer. Redeploy.
5. Buka domain, login admin dengan ADMIN_PASSWORD. Hubungkan Accurate, buka Daftar database, ambil ID database sendiri, isi ACCURATE_DB_ID pada Variables dan redeploy. Sinkron master barang.
6. Unduh template Excel, isi klasifikasi barang, mutasi dan dokumen BC, lalu import berurutan. Lihat laporan dan ekspor Excel.

Railway mengatur PORT otomatis. Dockerfile dan railway.json mengatur build, start dan health check. PostgreSQL menyimpan data antar-deploy; siapkan backup. Gunakan satu replika. Batasi akses ke tim uji, jangan berikan akses resmi ke Bea Cukai dahulu. Sinkron otomatis transaksi dan pekerjaan pesanan, role pengguna, audit detail dan rekonsiliasi masih belum selesai. API live dan deployment Railway belum diuji. Lihat README.md untuk batasan data.
